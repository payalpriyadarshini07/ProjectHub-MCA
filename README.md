# 🚀 ProjectHub — Collaborative Project Management Platform

ProjectHub is a collaborative project management platform designed to help developers **create projects, showcase their skills, discover opportunities, and collaborate with other developers**.

The platform provides a centralized space where users can manage their profiles, create and discover projects, connect with developers, send collaboration requests, and receive notifications.

## ✨ Features

### 👤 User Authentication & Profile
- User registration and login
- Secure password hashing using BCrypt
- Session-based authentication
- User profile management
- Developer bio and skills
- GitHub and LinkedIn profile links

### 📁 Project Management
- Create and manage projects
- View project details
- Search and discover projects
- Define required team members and skills
- Project collaboration support

### 🤝 Collaboration
- Follow and unfollow developers
- View followers and following
- Public developer profiles
- Send project join requests
- Accept or reject collaboration requests
- Project membership management

### 🔔 Notifications
- Collaboration request notifications
- Request acceptance/rejection notifications
- Follow-related notifications

## 🏗️ Architecture

ProjectHub follows a layered architecture:

```text
Browser
   ↓
JSP / HTML / CSS / JavaScript
   ↓
Servlet Controllers
   ↓
Service Layer
   ↓
DAO Layer
   ↓
Hibernate ORM
   ↓
MySQL Database
```

## 🔐 Security

The application includes:

- BCrypt password hashing
- Session-based authentication
- Input validation
- Protected user-specific pages
- Safe handling of external profile URLs

Database credentials are managed through environment variables rather than being hard-coded into the application.
